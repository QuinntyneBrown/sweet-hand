Pagination

The listing shows 24 caterers a page. Pagination says where you are in the 60 and steps through them, with the page in the URL so a shared link opens the same page.

WCAG 2.2 AAStatus: stable.load-more.pagination.result-count

Overview

Pagination sits under a long list: a quiet "Showing 1–24 of 60" line and a row of round page links. It appears on the caterer listing (24 per page, L2-002) and on long inbox, enquiry, queue, change and audit lists (20 per page). The page number lives in the URL, so Back, bookmarks and shared links all return to the same page (L2-003).

  • Use it whenever a list has more than one page. A list that fits on one page shows no pagination: the filtered listing ("2 caterers") ends after its cards.
  • Don't use infinite scroll or a "Load more" button. Both break the URL contract, hide the footer, and make "the 30th caterer" impossible to find again. The wrapper is called .load-more for historical reasons only.
  • Don't use pagination to move between steps of a task (that is a form flow) or between views of one object (use tabs).

Pepper red marks the current page: it is the "you are here" in the list of pages, which is exactly what the accent means.

Anatomy

  1. Result count.result-count: "Showing 25–48 of 60" in --text-body-sm, muted. Not a live region here; the count at the top of the page is.
  2. PreviousChevron-only link named "Previous page"; aria-disabled="true" on page 1.
  3. Page link44px circle (--control-height-md), muted label, named "Page 1".
  4. Current pagearia-current="page": pepper label, bold, a 1px pepper ring.
  5. NextChevron-only link named "Next page"; aria-disabled="true" on the last page.

Sizes

Every page link is a 44px circle at every breakpoint, so it already meets the phone target (L2-065.1). A smaller size would only matter for a dense table, and Sweet Hand tables do not paginate inline.

  • Disabled (previous on page 1, next on the last page) is an <a> with no href, role="link" and aria-disabled="true": 50% opacity, no pointer events, out of the tab order, still announced so the end of the list is clear.
  • Loading: while a new page loads, the row stays where it is; the grid shows caterer card skeletons and the top count announces "Loading caterers". Pagination is not repeated as a skeleton.
  • Offline (pages/caterers/offline): the saved page stays usable, but links to pages not yet saved should be aria-disabled, with the banner explaining why.

Responsive behaviour

  • All widths: the count and row stack and centre under the grid (.load-more, --space-16 above). Links stay 44px.
  • XS (below 36rem): up to seven items fit at 320px (‹ 1 … 6 … 54 ›). Show the current page only, plus first and last. Three pages need no gaps (‹ 1 2 3 › is 5 items).
  • SM and up: add one neighbour either side of the current page.
  • Inbox at LG: the list column is 20–26rem wide, so it keeps the XS arrangement.
  • The row is a single line today; a long sequence must not scroll sideways, so flex-wrap and centring are proposed (see Sources).

Theming

No component tokens. Page links read --color-fg-muted, hover adds --color-bg-subtle and --color-fg-default, the current page uses --color-fg-accent for label and ring (border-color: currentColor) and --color-accent-subtle on hover. In dark the accent lightens to a pepper that keeps 4.5:1 on near-black, and the hover fill becomes a dark stone. Re-skin through the semantic roles; never fill the current page with solid pepper, which would read as a primary button.

Accessibility

Role and pattern

<nav aria-label="Pagination"> containing a list of links; the current page carries aria-current="page". There is no APG widget for pagination; it follows the navigation landmark guidance with plain links, so it works without JavaScript.

Keyboard

KeyAction
Tab / Shift+TabMoves through previous, page links and next. Disabled arrows are skipped.
EnterOpens that page. Focus then moves to the results heading (or the h1), not the top of the document, and the document title becomes "Caterers, page 2 of 3 — Sweet Hand".

Focus

The shared ring sits 3px outside the 44px circle; on the current page it shows outside the pepper ring, so the two never merge.

Labelling

Number links are named "Page 2" (the visible "2" is inside the name, WCAG 2.5.3). Arrows are named "Previous page" and "Next page". The gap "…" is aria-hidden; the jump from "Page 1" to "Page 5" says enough.

Motion

Only the hover fill transitions (--duration-fast), and reduced motion zeroes it. Moving to a new page does not animate or smooth-scroll.

Touch

Every link is 44 × 44px. The links sit only 4px apart (--space-1), short of the 8px L2-065.1 asks for on phones, so the gap should grow to --space-2 (see Sources).

Content

  • Count format: "Showing 1–24 of 60" with an en dash and no spaces around it; thousands get a comma ("of 1,284"). The noun lives in the top count ("60 caterers"), so the bottom line does not repeat it.
  • Arrows are named "Previous page" and "Next page", never "Prev", "Older" or "More".
  • Never "Load more", "See more caterers" or "Page 2 of 3" as the only control.
  • The page number is a plain numeral; there is no "Page" prefix on screen.
