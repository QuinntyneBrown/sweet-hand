Filter list

The vertical cuisine column from the reference design: a plain text list where the one you picked turns pepper red. It is the most recognisable piece of Sweet Hand after the round photos.

Overview

On the caterer listing at 62rem and wider, a 15rem column to the left of the grid lists cuisines and areas as large, quiet text. Choosing "Jamaican" turns it pepper red and semibold, recounts every other option, and puts a removable "Jamaican" chip above the results. Nothing is boxed, ticked or highlighted: the colour of the word is the whole state. That restraint is the reference design's signature.

  • Use it for filtering a public listing where options are few enough to read (19 cuisines, 5 regions) and each option has a count.
  • Below 62rem the column is gone; the same choices move behind a filter trigger (a dropdown bar on tablets, a Filters sheet on phones) and use checkboxes, because a 44px text row with no box is hard to read as a toggle on a small screen.
  • Don't use it inside a form (use a checkbox or radio group), for a handful of mutually exclusive views (use tabs or a segmented control), or for long free-text lists such as 200 areas (use the area combobox).
  • The side navigation in the dashboard and operator console reuses .filter-list with aria-current="page", so "you are here" looks the same in every part of the product.

Anatomy

  1. Group title.filter-group__title, an h2 (or legend in a sheet) in --text-label, subtle. Names the group for aria-labelledby.
  2. "All" resetA link back to the unfiltered listing. aria-current="true" when no option in the group is chosen.
  3. Option.filter-list__item: a toggle <button aria-pressed>, --text-body-lg, muted, a full-width 44px row.
  4. Count.filter-list__count: caterers that would match with the other filters applied (L2-008.3), caption size, tabular numerals.
  5. Disabled optionCount 0: shown but disabled, in --color-fg-disabled.
  6. More toggle.filter-more: an underlined text button with aria-expanded that reveals the rest of the group.

Sizes

Options are always --text-body-lg in a 44px row. The large type is the design: it is what lets a column of plain words read as the main way to browse. A compact list would be a different component.

States

Real attributes wherever they exist: aria-pressed for chosen options, aria-current for "All" and navigation, disabled for zero counts, aria-expanded for the More toggle. Hover and focus are forced with data-state.

  • Selected keeps the count in pepper too (color: inherit), so the whole row reads as one choice.
  • Disabled appears when an option would return nothing with the current filters (filtered), when there are no caterers at all (empty) and while offline (offline, counts kept, every option disabled). A chosen option with a zero count stays enabled so it can be unchosen (no-results: Haitian in Durham).
  • Loading: options stay interactive while results refresh; the counts update with the results and the top .result-count announces the new total. No skeleton replaces the list.
  • More toggle, disabled: the stylesheet has no disabled rule for .filter-more yet, so it looks active (see Sources).

Responsive behaviour

  • LG and XL (62rem and wider): .browse__aside shows the groups in a --layout-sidebar-width (15rem) column, --space-10 between groups, beside a 3-column grid.
  • MD (48–62rem): the column hides. A filter bar of "Cuisine" and "Area" dropdowns sits above the grid (L2-009.2); inside each dropdown the options are checkboxes with "14 caterers" under the name.
  • XS and SM: a "Filters" button opens a full-height sheet with the same groups as checkbox lists (L2-009.1).
  • Every width: .active-filters sits above the results whenever something is chosen (L2-009.4). Chips wrap; "Clear filters" stays last.
  • Long names ("Dominican (Dominican Republic)", "Kittitian & Nevisian") wrap inside the 15rem column; the count follows the last word.

Theming

No component tokens; the list reads text roles only. Options are --color-fg-muted, hover --color-fg-default, chosen and current --color-fg-accent, disabled --color-fg-disabled, titles and counts --color-fg-subtle. Filter chips use --color-accent-subtle with an --color-accent edge. In dark, pepper lightens to --palette-pepper-300 so the chosen word still reads at 4.5:1 on near-black. In forced-colours mode colour disappears, so the chosen option is underlined instead.

To re-skin, change the semantic roles. Never add a background, tick or bar to the chosen row: if pepper text is not enough, the theme's accent is wrong, not the list.

Accessibility

Role and pattern

Each group is role="group" labelled by its title (or a fieldset/legend in a sheet). Options are toggle buttons with aria-pressed (APG Button, toggle); "All" is a link with aria-current="true". The More toggle uses aria-expanded (APG Disclosure). Chips sit in role="group" aria-label="Active filters".

Keyboard

KeyAction
Tab / Shift+TabMoves option by option; disabled options are skipped.
Enter, SpaceToggles the option. Results update in place (L2-008.6) and focus stays on the option.
Enter on MoreReveals the remaining options after the last visible one; focus stays on the toggle, which now reads "Fewer cuisines".
Enter on a chip's removeRemoves that filter; focus moves to the next chip, or to the results heading if none are left.

Focus

The shared pepper ring wraps the full-width row. It is offset 3px, so on a chosen (pepper) option the ring is still distinct from the word.

Labelling

The option's name includes its count. Add a visually hidden noun so it reads "Jamaican, 14 caterers" rather than "Jamaican 14". Chip removes are named "Remove Jamaican filter". The result count above the grid is role="status" aria-live="polite", so each change is announced ("2 caterers", L2-067.5).

Disabled options are exempt from contrast (WCAG 1.4.3) and also say "0" in text, so colour is never the only signal (L2-069.5).

Motion

Colour changes over --duration-fast; reduced motion makes it instant. Revealing more cuisines does not animate.

Touch

Rows are 44px tall and full width. The list only appears at 62rem and wider, where pointer input is the norm; phones get the sheet with checkbox rows instead. Chip remove buttons are 24px (--target-min) inside a 36px chip, meeting WCAG 2.5.8 with the chip's padding as spacing.

Content

  • Use the L2-007 names exactly: "Trinidadian & Tobagonian", "Barbadian (Bajan)", "Antiguan & Barbudan", "St. Lucian". Never "Trini", "Bajan" alone, or a generic "Caribbean". "Pan-Caribbean" appears only because caterers choose it.
  • Order: "All" first, then by count (most first), ties A to Z. Show six, then "More cuisines (11)" where the number is how many are hidden.
  • Group titles are one word: "Cuisine", "Area". Areas list the five regions: City of Toronto, Peel, York Region, Durham, Halton.
  • Counts are bare numerals in the list ("14"); in checkbox lists they read "14 caterers", "1 caterer".
  • The reset is "All" in the list and "Clear filters" beside the chips.
