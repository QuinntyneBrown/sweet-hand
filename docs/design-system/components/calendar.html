Calendar

The operators’ events calendar: a month table with up to 2 events a day, a week time grid, and an agenda for the selected day, with one colour and one name per event type.

Overview

The calendar shows the operators' directory of events by month, week or day, on admin calendar. Leah and Tomas use it to see what is on in Toronto and the GTA, spot clashes, and add an event on a chosen day. It is for operators only (L2-110).

  • Use the month view to see a month at a glance, with up to 2 events a day and "+N more".
  • Use the week view to compare times across days; it is a time grid from 8 a.m. to 11 p.m.
  • Use the agenda (.agenda) for a day's full list; it sits under the month on every screen and is the whole day view.
  • Use the events list to search or work through events in order; the calendar's error state links to it.
  • Don't use the calendar for a date picker in a form; date fields use the browser's native picker (text field).

Each event type has a colour (.ev--festival, --market, --trade, --truck, --popup, --workshop) shown as a dot, and the type key under the grid names them. Type is also in each event's page and agenda line, so colour is never the only cue.

Anatomy

  1. Toolbar(.cal-toolbar): previous and next icon buttons, "Today", the month title (.cal-toolbar__title, a live heading) and the Month/Week segmented control.
  2. Month grid(.cal in .cal-wrap): a real table, one row per week, Sunday first, with abbreviated day headers.
  3. Day cell(.cal__day): the date link (.cal__date), an optional holiday name (.cal__holiday), dots for narrow screens (.cal__dots) and the event list (.cal__events).
  4. Event(.cal-event + type): a link with a type dot, the start time (.cal-event__time) and a short title, clamped to 2 lines.
  5. More(.cal-more): "+N more", linking to the day.
  6. Type key(.type-key): one entry per event type.
  7. Agenda(.agenda): the selected day's events with time, title and meta.

Responsive behaviour

  • Below 48rem: day cells shrink to a 44px date with one dot per event type (.cal__dots); event lists and holiday names are hidden, and the agenda under the grid carries the detail. The toolbar title takes its own row.
  • 48rem and up: cells are 7.5rem tall with up to 2 events and "+N more"; the toolbar is one row with navigation, title and the view switch.
  • 100rem and up: .cal-layout--day puts the agenda in a 20rem column beside the grid.
  • Week view: the grid is at least 46rem wide and scrolls sideways inside .week; the page never scrolls sideways (L2-121 AC12).

Theming

The grid reads --color-border-default for lines, --color-bg-surface-sunken for days outside the month, --color-fg-subtle for headers and outside dates, --color-accent and --color-fg-on-accent for today. Event types map to semantic colours: festival --color-accent, market --color-success-solid, trade show --color-info-solid, food truck stop --color-warning-solid, pop-up --color-danger-solid, workshop --color-border-strong. Multi-day bars and week events mix the type colour with --color-bg-surface (16% and 14%), so they stay readable in both themes.

Accessibility

Role and pattern

The month is a data <table> labelled by the toolbar title, with column headers for the days. Navigation follows the grid pattern's keyboard model with a roving tab stop: one date link is in the tab order, and the arrow keys move between dates. Each date link's label names the day, "today" when it applies, and the event count: "Saturday 10 October, today, 1 event". Events are links to their event pages. The week grid is a focusable role="region" labelled with the week and the hours shown.

Keyboard

KeyAction
TabToolbar controls, then the selected date (one stop), then that day's events, then the agenda.
← →Previous or next day; crossing the month edge loads that month.
↑ ↓Same weekday in the previous or next week.
Home, EndFirst or last day of the week row.
Page Up, Page DownPrevious or next month.
EnterSelect the focused day and update the agenda (L2-121 AC9).

Focus

Date links, events and agenda items take the shared focus ring. A month change keeps focus on the same day number where it exists, and the live title announces the new month.

Labelling

Truncated titles ("Little Jamaica Market") are fine in cells because the link's full name is in the event page and the agenda. A continuing multi-day event carries its full title in visually hidden text before "continues". Cancelled and draft events add "(cancelled)" or "(draft)" in visually hidden text.

Touch

Below 48rem each date is a 44px target. Above it, events are at least 24px tall (WCAG 2.5.8) and "+N more" opens the day.

Content

  • The summary counts occurrences in the month: "19 events in October"; filtered, "2 of 19 events in October · trade shows and workshops".
  • Times use the product style: "10 a.m.", "6:30 p.m.", "12–8 p.m.", in Toronto time.
  • Cell titles are short forms of the event title ("Jerk Drum Wed."); the agenda uses the full title.
  • Ontario statutory holidays are labelled by name: "Thanksgiving", "Christmas Day", "Boxing Day".
  • The agenda heading reads "Today · Saturday 10 October", or the day alone when it is not today, with the count beside it.
