Component · Data display

Tag

Tags are the dietary and allergen facts on a dish: Halal, Vegan, Gluten-free, Contains nuts. They come from a fixed list the caterer ticks, so customers can rely on them and filter by them; they are never free text in a description.

Overview

Every dish on a caterer's menu can carry tags. They sit in a wrapping row under the dish name, price and description, on the public caterer page, in the caterer's menu manager and on operator review screens.

  • Dietary tag (.tag): what the dish suits — Vegetarian, Vegan, Gluten-free, Dairy-free, Halal — plus Spicy. Quiet outline, muted text.
  • Allergen tag (.tag--allergen): what the dish contains — Contains nuts, Contains shellfish. Mango tint and border so it is noticed before someone orders for a guest with an allergy.

Tags are structured data, not decoration: the dish dialog offers a fixed set of checkboxes ("Dietary tags"), the values are stored as a list, and the page renders them in one fixed order. Never type "nut-free" or "contains peanuts" into a description and never let a caterer invent a tag. They are also the caterer's own statement about their food; Sweet Hand does not test dishes or certify kitchens.

Not a tag: anything you can press or remove is a chip; a record's state is a status label; a count or "New" is a badge.

Anatomy

  1. ContainerPill, 24px tall (--target-min), hairline --color-border-default; allergen: --color-warning-bg fill and --color-warning-border.
  2. Icon (optional)14px (--icon-size-xs) outline icon, decorative. Recommended on allergen tags (warning triangle).
  3. LabelA value from the fixed list, --text-caption; allergens always begin "Contains".
  4. Row.tags: a <ul>, wrapping flex with --space-2 gaps, --space-1 above.

The full vocabulary

Eight values, in the order the dish dialog lists them and the page renders them. Adding a value (for example "Ital" for Rastafarian ital cooking, today covered by "Vegan") is a product decision: it goes into the fixed list, the filter and this page together.

Sizes

Tags have one size: 12px caption text in a 24px pill with an optional 14px icon. They label a dish, so they stay smaller than the dish name and price in every context.

States

Tags are not interactive: no hover, focus, pressed or disabled. The dish row may be hovered in the menu manager; the tags don't change. The states that exist are about the data.

  • None: a dish with no tags shows no row at all. Never write "No dietary information".
  • Changed: when a caterer adds or removes a tag on a published dish, the operator's change review shows the dish line before and after ("Escovitch fish · From $19 per person · Gluten-free").

Responsive behaviour

  • Tags never wrap internally (white-space: nowrap); the row wraps between tags. A dish with all eight tags takes three lines at 320px, which is fine.
  • The row is the full width of the dish at every breakpoint; it doesn't move beside the price on wide screens, so tags always read after the description.
  • In the menu manager (.edit-row) the row sits in the body column beside the move and edit buttons from 36rem; below that the buttons drop under the tags.

Theming

Dietary tags read --color-border-default and --color-fg-muted on whatever surface they sit on. Allergen tags read --color-warning-bg, --color-warning-border and --color-warning-fg. In dark the allergen fill is a deep mango with a light mango label, and the dietary outline is stone-750. Allergens use the warning family, never danger: an allergen is information, not an error; and never pepper, which means "selected".

Accessibility

Role and pattern

A <ul class="tags"> of <li class="tag">, read as "list, 3 items: Gluten-free, Halal, Spicy" after the dish name and description. No role, no interaction. Icons are aria-hidden="true".

Keyboard

KeyAction
TabNever stops on a tag.

Focus

None.

Labelling

The words carry the meaning, so the allergen tint is never the only cue: "Contains nuts" is explicit, and the optional warning icon adds a shape for people scanning. Screen readers hear the same words. Don't abbreviate ("GF", "V") — abbreviations are not announced meaningfully.

Contrast

Allergen edge (decorative)

Tag outlines are decorative: the text identifies the tag, so the hairline needs no 3:1.

Motion

None.

Touch

Not a target. Tags are 24px tall so that, if a future filter makes them tappable, they already meet the WCAG 2.5.8 minimum; at that point they become chips.

Content

  • Only the fixed values, written exactly: Vegetarian, Vegan, Gluten-free, Dairy-free, Halal, Contains nuts, Contains shellfish, Spicy. Sentence case, hyphenated "-free".
  • Fixed order: dietary (Vegetarian, Vegan, Gluten-free, Dairy-free, Halal), then allergens, then Spicy. The order never depends on which box was ticked first.
  • Don't repeat a tag in the description ("A vegan callaloo"); the description says how it is made: "Dasheen bush, okra and coconut, swizzled smooth."
  • Tags are the caterer's statement. Where tags are shown to customers, a short note should say so (proposed: "Dietary and allergen tags come from the caterer. Ask them about allergies in your enquiry.").
