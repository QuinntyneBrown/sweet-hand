Component · Data display

Stat

A stat is one number with a short label: 2 unread enquiries, a 4.7 rating, 60 published caterers. Stats open the caterer dashboard and the operator metrics page, in a grid of two or four.

Overview

Stats answer "how am I doing?" at a glance. They are flat: no card, no border, no icon — a quiet label above a large number, in a grid with generous gaps.

  • Caterer dashboard: four counts Kendra acts on — Unread enquiries 2, Open enquiries 3, Rating 4.7, Reviews 23.
  • Admin metrics: four headline figures for the chosen range — Published caterers 60 (+4 in this range), Enquiries 71, Replied within 48 hours 82%, Caterer page visits 39,700 — above the bar charts.

Use a stat for a single figure that stands on its own. Use a bar chart for change over time, a table for many figures to compare, and a description list for facts that aren't numbers ("Serves 20–300 guests"). A count badge is for unread counts on navigation, not for dashboards.

Anatomy

  1. Label.stat__label (<dt>): what is counted, --text-label, --color-fg-muted.
  2. Value.stat__value (<dd>): --text-h2, or --text-h1 in a grid; tabular numerals so figures line up and don't jump when they update.
  3. Delta (optional).stat__delta: a signed change with its period, small text, an arrow for direction and callaloo or sorrel for good or bad.

Delta up and down

The arrow shows direction; the colour shows whether that is good. More open reports is up but bad, so it takes --down styling with an up arrow. The sign and period are always in the text.

On its own a stat uses --text-h2 (30px); inside .stat-grid the value steps up to --text-h1 (36px on phones, 44px from 62rem). There is no small stat; for a figure in running text, write the number.

States

Stats aren't interactive. Their states are about the data: loaded, loading, not loaded (one figure failed while others loaded), zero, and large.

  • Loading: the grid keeps its shape with a label skeleton and a value skeleton per stat; the grid is aria-busy="true", skeletons aria-hidden="true", and one visually hidden status says "Loading metrics".
  • Not loaded (pages/admin-metrics/partial): the figure shows a dash and "Not loaded"; the chart below explains and offers "Try again". The dash is hidden from screen readers so it isn't read as "en dash".
  • Zero is a real value: show "0", never a dash. A whole range with no data is an empty state ("No activity in this range").

Responsive behaviour

  • Below lg (62rem): .stat-grid is two columns with --space-8 row and --space-6 column gaps. Labels wrap to two lines ("Replied within 48 hours"); values never wrap.
  • lg (62rem) and up: four columns in one row, and the h1 value grows from 36px to 44px with the type scale.
  • At 320px a column is about 8rem: "39,700" at 36px bold fits, a seven-character figure would not. Write full numbers (no "39.7k"); if a longer figure ever appears, the value steps down to --text-h2 below 22.5rem.

Theming

Stats read --color-fg-muted (label), --color-fg-default (value), --color-success-fg and --color-danger-fg (delta). No component tokens, no backgrounds. In dark the values become stone-100 on the stone-950 canvas and deltas use the light callaloo and sorrel steps. Never colour a value: a big green "60" says less than "+4 in this range".

Accessibility

Role and pattern

A description list: <dl class="stat-grid"> with one <div class="stat"> per figure, holding <dt> label, <dd> value and optional <dd> delta. Screen readers read "Published caterers, 60, plus 4 in this range". It is not a heading structure; the page's h1 and section headings stay above it. A single stat outside a grid is a <div class="stat"> with <span> parts (the examples on this page), because a lone <dd> keeps the browser indent.

Keyboard

KeyAction
TabNever stops on a stat. If a stat should lead somewhere (Unread enquiries → inbox), the section heading's link does that, not the number.

Focus

None.

Labelling

Labels say what and, where it matters, over what period: the page subtitle states the range ("31 Aug – 10 Oct 2026 · by week · Toronto time"), so labels don't repeat it. Add hidden context where the number alone is ambiguous: "4.7 out of 5". Deltas carry their sign and period in text; the arrow is aria-hidden="true".

Motion

Values don't count up or animate. When a range changes, figures are replaced in place; tabular numerals stop the layout shifting.

Touch

Not a target.

Content

  • Labels are short noun phrases in sentence case: "Unread enquiries", "Caterer page visits". Spell units out: "Replied within 48 hours", not "48 h".
  • Numbers in Canadian English: comma thousands ("39,700"), "%" without a space ("82%"), one decimal for ratings ("4.7"), CAD as "$2,600" where money appears.
  • Deltas: sign, number, unit, period: "+4 in this range", "−4 points in this range", "No change in this range". Never a bare "+4".
  • Averages say so: "2,578 avg".
