Container and grid

The layout primitives every Sweet Hand screen is built from: one centred container, a 4, 8 or 12 column grid, stack and cluster for rhythm, and five product layouts for the listing, caterer page, work areas, inbox and sign-in.

Overview

Layout classes carry no colour and no meaning; they only place things. Generous white space is part of the brand, so the gaps are large and come from tokens that grow with the screen. Use these instead of one-off margins: a screen built from them reflows from 320px to 2560px without sideways scrolling (L2-005.6, L2-069.3).

  • Container (.container): wraps every page's main. Centred, at most 90rem including margins, side margin from --layout-margin (16 → 32 → 48 → 80px). .container--narrow caps it at 42rem for reading pages.
  • Stack and cluster: .stack spaces children vertically (--space-4; --sm 8px, --lg 32px); .cluster lays them in a wrapping row (--between, --end).
  • Grid: .grid uses the layout columns (4 / 8 / 12) and gutters (24 / 32 / 40px); .grid--auto fits as many 18rem tracks as there is room for.
  • Page shell: .page (header, growing main, footer), .page-intro (the h1 block), .page-intro__row (title with a primary action), .section-gap, .prose.
  • Product layouts: .browse (filter column + results), .caterer-layout (content + enquiry panel), .work-layout (side nav + work + preview), .inbox-layout (list + thread), .auth (one narrow column).

For a surface around content, see card; for the listing's photo grid, see caterer card. Spacing values themselves are documented in Spacing and Layout.

Anatomy

  1. Page intro.page-intro holds the one h1 and a muted subtitle; --space-8 above and --space-10 below, growing to 64 / 48px from 62rem.
  2. Primary action.page-intro__row pushes the screen's one ink button to the end; it wraps under the title on phones.
  3. Margin--layout-margin inside .container: 16px, 32px from 48rem, 48px from 62rem, 80px from 75rem.
  4. Column--layout-columns: 4, then 8 from 48rem, then 12 from 62rem.
  5. Gutter--layout-gutter: 24px, 32px from 48rem, 40px from 62rem.

  • Every column uses minmax(0, 1fr), so long words (a 90-character caterer name, an email) wrap instead of forcing sideways scroll.
  • .page uses 100dvh, so the footer sits at the bottom of short pages without jumping when the phone's address bar hides.
  • Sticky children (the enquiry panel at --space-8 from the top, the preview pane) never cover focused content; the sticky bottom bar is offset by .has-sticky-cta.

Theming

Layouts read no colour tokens; the page canvas comes from body. They read the layout tokens (--layout-*) and the spacing scale, which are the same in light and dark. To give a product area a different density, override the layout tokens on a wrapper (for example a tighter --layout-gutter for a data-heavy operator page) rather than adding margins to children. Themes never change layout.

Accessibility

Role and pattern

Layouts are built on landmarks: header, main id="main" (the skip link target), aside aria-label="Filters", nav aria-label="Dashboard", footer (APG Landmark regions). One h1 per page, in .page-intro.

Keyboard

KeyAction
Tab (first press)Shows "Skip to main content", which jumps past the header into main (L2-067.3).
Tab / Shift+TabFollows source order, which matches visual order at every breakpoint (L2-067.1). .browse places the filter column with grid-template-areas but keeps it after the title in the source.

Focus

Layouts never clip focus rings: containers do not set overflow: hidden, and sticky elements leave room (scroll-padding-top equals the header height).

Labelling

Each repeated landmark has a name: the filter column "Filters", the results section labelled by its (visually hidden) "Results" heading, the preview pane "Your listing card".

Motion

Layouts do not animate. Smooth scrolling to anchors is turned off under reduced motion.

Touch

At 320px with 16px margins the content box is 288px; every layout fits it without sideways scrolling, and at 200% zoom on a 1280px window the phone layout takes over (WCAG 1.4.10, L2-069.3).

Content

  • The page intro's h1 is a noun for the place: "Caterers", "Inbox", "Food safety", "Review queue". A caterer or person name is the h1 on their page.
  • The subtitle is one muted line of fact: "19 cuisines · shown in filters and caterer profiles", "Your food handler certificate". No welcome messages.
  • Prose stays within --layout-measure (62 characters) and uses Canadian English.
  • Leave space empty. A gap is not a slot for a tip, a banner or a promotion.
