States

Layouts have no pointer or focus states. Structural states: loading (aria-busy; the caterer panel aria-hidden), thread open, solo, preview, sticky CTA room. Each frame is a real viewport.

AC-14, AC-19, AC-20

Product layouts by viewport

Wide frames are real 800 and 1280 px viewports drawn smaller. Component CSS uses viewport media queries, so only frames show the real breakpoints.
