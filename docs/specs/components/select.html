Filter selects: a real "All …" first option; "Show by" ordered by meaning; applied by Apply, never on change. AC-3, AC-4

Sizes

One size: 44 px with 16 px text in forms and toolbars. Width follows the field (full width in forms, at least 10rem in a toolbar).

States

Hover and focus are forced with data-state; invalid and disabled use aria-invalid and disabled. There is no read-only select: a busy form disables it and keeps its value.
