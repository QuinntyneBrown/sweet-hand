Responsive

At 768 px the Cuisine dropdown opens under its trigger in the filter bar. Below 48rem there are no filter dropdowns (the Filters sheet takes over); a popover used in a .filter-bar starts at the bar's left edge (required, D-8: today's CSS only does this for the filter dropdown) and its small buttons grow to 44 px.
