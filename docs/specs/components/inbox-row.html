Responsive

Each frame is a real viewport. Below 62rem the list is shown alone; from 62rem it sits in a 20–26rem column beside the thread with the current row marked. Names and summaries truncate; time and status never do.

AC-10 (navigation and focus return are behaviour); AC-19: at 200 % zoom a 1280 px window behaves like the 640 px layout
