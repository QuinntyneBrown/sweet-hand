Sizes

One size: --text-label at --font-size-xs in a pill at least --target-min tall. On an icon button the count's minimum drops to --icon-size-md and it pins to the top-right corner (shown under Variants).

Responsive

The badge itself never changes across breakpoints; the frames prove it fits where the header puts it at phone width and that it drops to the next line as a whole pill in a wrapping title.
