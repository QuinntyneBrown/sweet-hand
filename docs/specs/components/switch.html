Variants

Label end (default): track, then the setting's name; the description says what "on" means. Illustrative labels from the design system. AC-1, AC-2, AC-4, AC-10
Label start in a settings row: the text leads, the track is pinned to the end, the whole row toggles. Required (D-8): the track never wraps under the text. AC-3, AC-15

The preview appears once you add a cover photo.

Disabled only with the reason on screen; only the track dims (D-4). AC-6

States

On and off use checked; hover and focus are forced with data-state (on + hover needs data-state="checked" data-hover).
