Responsive

Each frame is a real viewport. Below 48rem the text links and avatar hide and the shortcut and Menu show, 8 px apart (required, D-2); below 24rem the area tag hides (required, D-7). At 200 % zoom on a 1280 px window the viewport is 640 px, so the phone layout applies.
