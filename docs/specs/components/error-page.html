Sizes

One size: the 34rem centred column with the display heading and large buttons. The heading steps from 48 px to 64 px at 62rem through --font-size-5xl (see Responsive). AC-19

States

The page is static; its actions carry the states. Hover and focus are forced with data-state; the rest use the real attributes.
