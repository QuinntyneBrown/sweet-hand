Responsive

Each frame is a real viewport: 1 column below 36rem, 2 from 36rem, 3 from 62rem (and at XL, D-3). The long name clamps; the long line wraps; nothing scrolls sideways at 320 px.

AC-25: at 200 % zoom a 1280 px window behaves like the 640 px layout (2 columns)
