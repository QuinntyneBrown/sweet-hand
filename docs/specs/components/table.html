Responsive

Each frame is a real viewport. The audit log keeps its 6 columns and scrolls inside .table-wrap; the page never scrolls sideways. Narrow tables fit at 320 px and their row headers wrap. Row actions are always visible on touch (hover: none) and 44 px tall below 48rem.
