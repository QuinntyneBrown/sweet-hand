Variants

Pin types

  • Storefront pins (.pin--restaurant, --takeout, --grocery, --bakery) use a teardrop head that points at the address.
  • Food truck (.pin--truck) uses a square head: it marks the day's stop, not a fixed address.
  • Draft (.pin--draft, added to a type) is an outline with a coloured letter. It marks a place that is not yet listed.
  • Cluster (.pin-cluster) replaces pins whose heads would overlap at the current zoom; activating it zooms in on them.

Map with list (.map-layout)

The places map pairs the map with an A-to-Z section list (.map-layout__list). Selecting a list row selects the pin, and the reverse; the current row takes aria-current="true".

Small map (.map--sm)

Use the arrow keys to move the pin.

The place page and the place editor show one pin on a canvas that fits its container instead of scrolling. In the editor the pin can be dragged, or moved with the arrow keys, to correct a geocoded address (L2-113).

Sizes

Two sizes: the full map (.map, canvas at least 40rem wide and scrolling inside the frame) and the small map (.map--sm, canvas at 100% of its container). Pins are one size: a 44px target (--target-comfortable) with a 1.75rem head, 1.25rem in the legend.

——
  • Hover grows the head by 20%. Focus adds the shared focus ring around the head. Selected (aria-pressed="true") grows the head, adds a ring in the pin's colour and raises the pin above its neighbours.
  • Card open: the selected pin's card sits above the pin, or below it when there is no room above inside the frame (the selected mock clips it at the top edge); Escape or the close button closes it and returns focus to the pin.
  • Loading (loading): the list shows skeleton rows, the map frame shows the base map with no pins, and one visually hidden status says "Loading places on the map".
  • Empty: no place has a pin. The base map stays, with a centred card, "No places on the map yet", and "Add place" over it.
  • Error: the map or the places failed. An error empty state replaces the map and offers "Use the list".
