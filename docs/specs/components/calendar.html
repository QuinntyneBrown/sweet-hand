More
  • +2 more
  • Today (aria-current="date"): a pepper circle behind the date, the one use of the accent in the grid.
  • Selected (aria-selected="true"): an ink ring; the agenda below shows that day.
  • Cancelled or skipped (.cal-event--cancelled): struck through and subtle, with "(cancelled)" in visually hidden text, so the state is not carried by style alone.
  • Draft (.cal-event--draft): an outline dot, with "(draft)" in visually hidden text and in the agenda.
  • Loading: the grid keeps its headers and shows skeletons in each cell; aria-busy="true" on .cal-wrap.
  • Empty month: the grid stays, with holidays, and an empty state follows it.
  • Error: an error empty state replaces the grid and offers "Use the list".

AC-18

Responsive

  • Below 48rem: day cells shrink to a 44px date with one dot per event type (.cal__dots); event lists and holiday names are hidden, and the agenda under the grid carries the detail. The toolbar title takes its own row.
  • 48rem and up: cells are 7.5rem tall with up to 2 events and "+N more"; the toolbar is one row with navigation, title and the view switch.
  • 100rem and up: .cal-layout--day puts the agenda in a 20rem column beside the grid.
  • Week view: the grid is at least 46rem wide and scrolls sideways inside .week; the page never scrolls sideways (L2-121 AC12).
