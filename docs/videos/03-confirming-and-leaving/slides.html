From the email, then again

303 to /?remove=…, the page posts the token. A second visit names no address.

RFC 8058 one-click unsubscribe

List-Unsubscribe: <https://…/api/launch-list/unsubscribe?token=…>
List-Unsubscribe-Post: List-Unsubscribe=One-Click

GET  /api/launch-list/unsubscribe?token=…   → 303 /?remove=…   record still there
POST /api/launch-list/unsubscribe?token=…   → 200              record gone, 0 tokens left

Real responses from the API on PostgreSQL. The POST is @WithoutCsrf(): its token is its only authority, and it can only delete.

Things to remember

  • It only counts once confirmed: one single-use link, 48 hours
  • Tokens are posted after load and cleared from the address bar
  • One click to leave, from the page, the email or the mail client, and it deletes
