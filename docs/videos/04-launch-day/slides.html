Launch day

One email to every confirmed address, then the list closes and is deleted

One explicit command

$ cd backend
$ npm run launch-email
  • No web UI: nothing on a page can send it (L2-101.1)
  • Runs against DATABASE_URL, like npm run migrate and npm run seed

backend/src/launch-list/send-launch-email.ts

What it does

  1. Records the launch: sign-ups and confirmations close (HTTP 410)
  2. Queues one launch-day email per confirmed address, marking each record in the same transaction

Pending addresses get nothing; removed addresses no longer exist.

Safe to run twice

$ npm run launch-email
{"queued":2,"alreadyQueued":0}
$ npm run launch-email
{"queued":0,"alreadyQueued":2}
