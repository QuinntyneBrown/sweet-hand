# Background music

Every deck names this track with `<body data-music="../assets/music/<file>">`. The video
builder lays it under the narration, looped if it is shorter, at `data-music-db` (default
−10.8 dB, the level of the Goodwork pitch video), faded in, and holds the last slide 3 s after
the narration so the music plays on and fades out. Keep the provenance of every track here.
